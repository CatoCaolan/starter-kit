# Merge log (the gate's audit)

*Single-writer: the gate (`members/gate.md`). One line per landed merge: date · branch (what landed) · verdict · the gate's hand. A code merge carries the fuller shape from the gate's charter: date · branch (what landed) · new main SHA · author seat · reviewer · verdict. Nothing lands unlogged; a merge with no line here did not go through the gate.*
