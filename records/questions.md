# Questions for the human: queued, not blocking

*Single-writer: the orchestrator. Some facts live only in human memory: no scout can reach them, and a sweep that misses them reports absence-from-swept-surfaces, not absence-in-world. Queue such questions here the moment they're identified, ask when the human has bandwidth, and file the answer to `records/decisions.md`. Row shape: date · question · who queued it · why it's unanswerable from disk · state (NEVER-ASKED / SENT / RECEIVED / ANSWERED) · date the state was set. SENT is written by the asker; RECEIVED is written only by the receiving party. ANSWERED rows file their answer to `records/decisions.md`.*
